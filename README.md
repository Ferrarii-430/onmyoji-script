## 快速开始

1. 下载最新发行版本的 `yys-script-x64.zip`，完整解压到文件夹。
2. 【**右键使用管理员身份**启动】 `yys-script.exe` 即可使用（**必须以管理员身份启动，否则无法注入**）。
3. 使用默认设置，支持游戏窗口最小化时运行脚本。

## 使用教程

软件的核心逻辑就是「**识别 → 点击 → 等待**」不断循环。脚本逻辑完全依靠自主设置、自由发挥，每次爬塔或者周年庆 999 只需简单截图设置即可完成，解放双手。

1. 选择方案 → 添加方案内容。

   ![选择方案](img/img1.png)

2. 输入需要的数据。分数阈值是 0~1 之间的数字，建议填 0.55~0.75；点击「开始截图」选择需要识别的图片，OK 保存即可。

   ![输入数据](img/img2.png)
   ![截图识别](img/img3.png)

3. 设置循环次数（次数为 0 时表示无限循环），点击「启动」即可开始执行脚本逻辑。

   ![设置循环](img/img4.png)

4. 中途可以加入「是否有勾协」的判断，防止被鬼使黑。
